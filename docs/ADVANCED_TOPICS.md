# Advanced topics

The advanced contract is optional and separate from the browser game's main
contract. Its dispute-capable protocol, SDK, tests, and current limits are
documented in the [advanced protocol reference](../advanced/README.md). It is
not wired into the browser game.

## Dispute-capable contract and trust

The separately maintained advanced topic repairs the reviewed canonical-proof,
deadline, dispute-precedence, and entropy-withholding findings. It remains an
optimistic protocol: participants must monitor challenge windows, clients still
need reliable off-chain message exchange and local persistence, and the arena's
maintenance key can replace verifier keys. The advanced contract has focused
simulator and local-ledger tests, but no production UI integration or formal
security audit.

The advanced ABI and ledger layout differ from the historical advanced
contract. Always deploy it to a fresh address; do not reuse an older advanced
deployment or its deployment JSON.

## Check the advanced contract

From the repository root, after installing the locked dependencies and Compact
compiler described in the [main README](../README.md), compile its complete
and stub contracts, verify its own generated keys, then run its TypeScript and
simulator checks:

```bash
npm run compact:advanced
bun run keys:verify:advanced
npm run typecheck:advanced
npm run test:advanced
```

Its focused local-ledger scenarios require a fresh local stack and the full
proving artifacts generated by `npm run compact:advanced`:

```bash
npm run test:e2e:advanced
```

## Deploy to another network

These steps deploy the main browser-game contract. The separate advanced
contract has its own deployment layout and is not connected to the browser UI.

Copy [`.env.example`](../.env.example) to `.env` and select the target network.
`MIDNIGHT_*` values configure the deploy and maintenance scripts; keep
`MIDNIGHT_WALLET_SEED` private. `VITE_*` values are public build-time browser
configuration, with network-suffixed arena and service endpoints selected by
`VITE_NETWORK_ID`.

Deploy the contract once with the target network's Midnight endpoints. The
deploy command prints the `VITE_ARENA_ADDRESS_<NETWORK>` entry to retain for
later builds:

```bash
bun run deploy
```

On preview, preprod, or mainnet, players connect an extension wallet and pay
their own fees. Browser-facing endpoints must use HTTPS/WSS when the site is
served over TLS. The full Linux hosting runbook, including the relay and nginx
configuration, is in [`deploy/SERVER_SETUP.md`](../deploy/SERVER_SETUP.md).
